# Release policy

- `x5-1.2.1/` is the immutable, real-device-verified X5/cv182x snapshot.
- `adaptive-1.3.0/` is the width-normalized, flexible-height build intended for broader Falcon device testing.
- Every release directory contains its AMR, source ZIP and `SHA256SUMS.txt`.
- A build being present here does not claim compatibility with untested device models.
